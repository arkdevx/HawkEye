# HawkEye 🦅

A modular open-source reconnaissance and OSINT toolkit for Linux.

## Overview

HawkEye is a command-line toolkit designed to bring commonly used reconnaissance and information-gathering tasks into a single, organized interface.

The project focuses on modular design, clear output, and maintainable Python code.

## Features

- WHOIS information
- DNS lookups
- IP information
- SSL certificate inspection
- HTTP header analysis
- robots.txt inspection

## Project Status

🚧 **Under Development**

HawkEye is currently in active development. Features will be added progressively as the project evolves.

## Supported Platforms

- Kali Linux
- Debian-based Linux distributions
- Ubuntu
- Parrot OS
